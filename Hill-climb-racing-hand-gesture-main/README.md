# Hill Climb Racing Hand Gesture 🎮


A fun and interactive **Hand Gesture Controlled Game** where you can play the classic **Hill Climb Racing** using hand gestures. The project uses **Python**, **OpenCV**, **MediaPipe**, and **keyboard input simulation** to detect hand gestures through a webcam and control the game without physically using the keyboard.

## Features

- **Accelerator**: Control acceleration using an open hand gesture.
- **Brake**: Control braking using a closed fist gesture.
- **Single-Hand Control**: Control the game using the gesture detection implemented in `main.py`.
- **Two-Hand Control**: Alternative hand gesture control implementation available in `main2.py`.
- **Real-time Hand Detection**: Detects hand gestures in real-time using your webcam.
- **Computer Vision**: Uses OpenCV and MediaPipe for real-time hand tracking.
- **Keyboard Control**: Simulates keyboard inputs to control the game.
- **Python Powered**: Built using Python 3.12.
- **Interactive Gameplay**: Provides a hands-free gaming experience.

## Prerequisites

Before running this project, ensure you have the following installed:

- **Python 3.12**
- **OpenCV**
- **MediaPipe**
- **Pynput**
- **Webcam**
- **Windows OS**
